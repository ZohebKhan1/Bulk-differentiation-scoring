1 Introduction

Bulk RNA-seq differentiation studies are typically sampled at discrete timepoints, even though individual samples may progress through differentiation at different rates. This tutorial develops a reference-trajectory method that uses gene expression to estimate each sample’s continuous position along a known differentiation time course.

The method uses reference samples to define both the expression space and the trajectory through that space. It then assigns each sample a predicted reference time, a normalized differentiation score, and a distance from the fitted trajectory.

The workflow has four operations:

  1. select temporal genes from the reference samples;
  2. train a centered, unscaled PCA model on the reference-timepoint mean profiles;
  3. join ordered day centroids into a piecewise-linear trajectory; and
  4. project samples to their nearest position on that finite trajectory.

The worked analysis is maintained in scripts/01_build_tutorial_objects.R. The reusable public implementations are functions/select_temporal_genes.R and functions/score_differentiation_timing.R. tutorial/tutorial.Rmd is the authoritative tutorial source; docs/ contains the generated GitHub Pages site.

1.1 Reuse the scorer

The scorer assumes that temporal genes and normalized expression values have already been defined. It trains the reference PCA and day-centroid polyline, projects all supplied samples into that fixed space, and returns predicted time, a normalized differentiation score, and projection-distance diagnostics. It does not select genes, normalize counts, draw figures, or write files.

base_url <- paste0(
  'https://raw.githubusercontent.com/ZohebKhan1/',
  'pca-maturation-scoring/main/functions'
)

download.file(
  paste0(base_url, '/score_differentiation_timing.R'),
  'score_differentiation_timing.R'
)
source('score_differentiation_timing.R')

The primary inputs are:

  • expression_matrix: normalized expression, with unique gene IDs in rows and unique sample IDs in columns;
  • metadata: one row per expression sample;
  • temporal_genes: gene IDs selected independently of the samples being evaluated;
  • sample_id_col and time_col: metadata columns containing sample IDs and numeric reference times;
  • reference_samples: an optional vector of sample IDs that distinguishes training references from samples to score. If omitted, all samples are references.

The scorer automatically retains the smallest number of PCs explaining at least 99% of the between-timepoint variance. The output list contains scores, pca_coordinates, pca_fit, pca_variance, the selected n_pcs, centroid_polyline, retained temporal_genes, and the reference_time_range. Because projection is clipped to finite centroid-to-centroid segments, predicted times and normalized scores are bounded by the first and last reference timepoints. A score outside 0 to 1 is therefore not part of this implementation’s contract.

2 Example data used in the workflow/tutorial

The worked example uses processed data derived from public NCBI GEO accession GSE122380, a bulk RNA-seq time course of human induced pluripotent stem cell differentiation into cardiomyocytes reported by Strober, Elorbany, Rhodes and colleagues. The analysis includes 192 samples from 13 cell lines collected across differentiation days 1 through 15. These samples form the reference cohort used for temporal-gene selection, PCA training, day-centroid trajectory fitting, and internal validation.

The repository bundles aligned sample metadata, a raw gene-count matrix, and a variance-stabilized expression matrix. The active input contains no perturbation samples. These tracked RDS files are the reproducible starting point for the workflow; raw-read acquisition, sequencing and sample-level QC, alignment, quantification, upstream gene filtering, and construction of the VST matrix are outside the repository’s scope. The tutorial therefore reproduces the analysis from processed inputs rather than from FASTQ files.

3 Scoring workflow

  1. Identify temporal genes in the reference samples. Apply three filters in sequence and retain genes that pass all three:
    • maximum day-mean TMM CPM at least 10;
    • DESeq2 LRT adjusted \(p\)-value below \(10^{-7}\) for categorical day after accounting for cell line; and
    • day-mean VST expression range at least 0.6.
  2. Train the reference PCA. Average temporal-gene VST expression within each reference day, center each gene without variance scaling, and retain the smallest number of PCs explaining at least 99% of the between-day variance.
  3. Construct the day trajectory. Calculate the centroid for each reference day in retained PC space and connect the ordered centroids with finite line segments.
  4. Project each sample. Find its nearest point on the trajectory to obtain predicted time, a score normalized from 0 to 1, and squared projection distance.

3.1 Select temporal genes

Temporal-gene selection applies three filters in sequence. A gene is retained only if it satisfies every criterion.

The LRT compares a full count model containing cell line and categorical differentiation day with a reduced model containing cell line alone:

\[ \mathrm{full}: y \sim \mathrm{cell\ line} + \mathrm{day}, \qquad \mathrm{reduced}: y \sim \mathrm{cell\ line}. \tag{1} \]

The likelihood-ratio statistic is

\[ \mathrm{LR} = 2\left(\ell_{\mathrm{full}} - \ell_{\mathrm{reduced}}\right), \tag{2} \]

where \(\ell\) is the maximized model log likelihood. This tests whether categorical day improves fit after accounting for cell-line structure; it does not assume a linear expression trend.

source('functions/select_temporal_genes.R')

temporal_selection <- select_temporal_genes(
  raw_counts = counts,
  vst_expression = vst,
  metadata = metadata,
  sample_id_col = 'sample_id',
  time_col = 'day_numeric',
  adjustment_covariates = 'cell_line'
)
temporal_genes <- temporal_selection$temporal_genes

The three filtering thresholds default to the values used above: maximum day-mean TMM CPM at least 10, LRT adjusted \(p\)-value below \(10^{-7}\), and day-mean VST range at least 0.6. adjustment_covariates defines the metadata columns included in both LRT models; use NULL for an unadjusted time test or a character vector such as c('cell_line', 'batch') for multiple covariates. The function adds categorical time to the full model automatically. Numeric adjustment columns remain continuous; character and logical columns are treated as factors.

To select temporal genes from one reference cohort, provide a metadata column and value together. For example,

reference_group_col = 'condition',
reference_group_value = 'control'

restricts CPM filtering, the LRT, and VST-range filtering to samples labeled control in metadata$condition. Omitting both arguments uses all samples. This pair controls which samples enter gene selection; it is not a DESeq2 coefficient reference level, which does not affect this omnibus LRT.

3.2 Train the PCA reference space

Let \(X \in \mathbb{R}^{n \times p}\) be normalized reference expression for \(n\) samples and \(p\) temporal genes. For each of \(m\) reference timepoints, the scorer first calculates its mean expression profile \(\mathbf{m}_j\). PCA is fitted to the \(m \times p\) matrix of timepoint means after centering each gene without variance scaling. If \(\boldsymbol{\mu}_M\) is the across-timepoint gene mean and \(W_k\) contains the retained loading vectors, then

\[ \mathbf{m}_j = \frac{1}{|I_j|}\sum_{i \in I_j}\mathbf{x}_i, \qquad \mathbf{z}_i = (\mathbf{x}_i - \boldsymbol{\mu}_M) W_k. \tag{3} \]

The scorer chooses the smallest \(k\) for which cumulative PCA variance is at least 99%. This choice is made from reference-timepoint means only; samples being evaluated cannot affect it. The rule retained seven PCs in the complete reference fit and in every validation fold. PC1 is flipped for figure readability when needed so it increases with differentiation day; a sign flip does not alter Euclidean projections or scores.

3.3 Fit and score the day-centroid polyline

For each ordered reference day \(t_j\), the mean PCA coordinate is

\[ \mathbf{c}_j = \frac{1}{|I_j|}\sum_{i \in I_j}\mathbf{z}_i, \qquad j = 1,\ldots,m. \tag{4} \]

The ordered centroids define a piecewise-linear trajectory. Segment \(j\) begins at \(\mathbf{a}_j=\mathbf{c}_j\), ends at \(\mathbf{b}_j=\mathbf{c}_{j+1}\), and has direction \(\mathbf{v}_j=\mathbf{b}_j-\mathbf{a}_j\). For sample \(i\), the fraction along segment \(j\) is

\[ \alpha_{ij} = \operatorname{clip}_{[0,1]} \left( \frac{\langle \mathbf{z}_i-\mathbf{a}_j,\mathbf{v}_j \rangle} {\langle \mathbf{v}_j,\mathbf{v}_j \rangle} \right). \tag{5} \]

The closest finite-segment projection is selected:

\[ \mathbf{q}_{ij}=\mathbf{a}_j+\alpha_{ij}\mathbf{v}_j, \qquad j^\ast=\underset{j}{\operatorname{argmin}} \left\lVert\mathbf{z}_i-\mathbf{q}_{ij}\right\rVert^2. \tag{6} \]

The corresponding predicted time and normalized score are

\[ \widehat{t}_i=t_{j^\ast}+\alpha_{ij^\ast}(t_{j^\ast+1}-t_{j^\ast}), \qquad s_i=\frac{\widehat{t}_i-t_{\mathrm{start}}}{t_{\mathrm{end}}-t_{\mathrm{start}}}. \tag{7} \]

Zero-length centroid segments are omitted. The method assumes that ordered centroids describe a meaningful trajectory in retained PC space. A self-approaching or folded trajectory can make nearest-segment assignments biologically ambiguous; squared projection distance should therefore be inspected when adapting the scorer.

4 Internal cell-line cross-validation

Leave-one-cell-line-out validation repeats temporal-gene selection, PCA training, and polyline fitting using the remaining cell lines, then scores samples from the held-out cell line. The count-based DESeq2 LRT is refit in each fold. The tracked VST matrix is shared across folds because the upstream transformation pipeline is not available; the result is therefore internal validation conditional on this processed cohort, not an external transferability estimate. The tutorial uses a compatible optional local cache when present and otherwise runs the complete validation in memory without saving the result.

Fold-specific temporal genes are also divided into maturation and progenitor sets by the sign of their Spearman correlation with day. The reported accuracy metrics use the complete temporal set. All 13 held-out cell lines contribute; cell line 19190 is omitted only from the per-cell-line panel grid so the display remains a balanced 3-by-4 layout.

5 Interpretation and adaptation

The score estimates position along this reference trajectory. It does not establish cell quality, differentiation efficiency, lineage identity, potency, or biological directionality.

For a new study, select temporal genes and train the PCA/polyline model in an appropriate reference cohort, then project test samples without refitting that model. Before comparing scores across datasets, verify gene identifiers, normalization, shared feature support, batch structure, reference-time coverage, and projection distance.
